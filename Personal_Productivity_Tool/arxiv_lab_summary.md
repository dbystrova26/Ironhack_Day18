# Lab Summary: arXiv Research Summarizer (n8n + Notion)

This lab builds an end-to-end automation workflow that accepts an arXiv paper URL via webhook, fetches the paper metadata from the arXiv API, parses the XML response to extract title, authors, abstract, and category, then uses the Anthropic Claude API to generate a plain-language 2-3 sentence summary, and finally stores everything in a Notion database — returning a success confirmation to the caller. The main challenge encountered was arXiv's aggressive IP-based rate limiting, which blocked the n8n server after repeated test requests and required waiting 30-60 minutes between testing sessions; a key lesson is to test API-heavy workflows sparingly and implement retry logic with exponential backoff from the start. One improvement idea would be to add a caching layer (e.g. checking if the paper ID already exists in Notion before calling arXiv) to avoid duplicate processing and reduce unnecessary API calls, combined with a proper error notification system that alerts via email or Slack when the workflow fails silently.
